# 🚀 Node.js, Express & MongoDB REST APIs Collection

Welcome to the **REST APIs Collection**! This repository contains a comprehensive set of backend RESTful API services built with **Node.js**, **Express.js**, and **MongoDB**. Each API module is organized into its own structured folder and tested thoroughly using **Postman**.

---

## 🛠️ Tech Stack & Tools

* **Backend Framework:** Node.js & Express.js
* **Database:** MongoDB (Mongoose ORM)
* **API Testing:** Postman
* **Version Control:** Git & GitHub
